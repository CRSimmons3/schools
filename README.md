# Schools in England

## Objective
To explore available data about schools in England and the areas around them

## Data
Data about schools was collected by OFSTED.  It was taken from https://www.gov.uk/government/statistical-data-sets/monthly-management-information-ofsteds-school-inspections-outcomes

Data about population in local authorities were estimates calculated from census data by the Office for National Statistics, taken from https://www.ons.gov.uk/peoplepopulationandcommunity/populationandmigration/populationestimates/datasets/estimatesofthepopulationforenglandandwales

Data about population densities in local authorities are estimates calculated from census data by the Office for National Statistics, taken from https://www.ons.gov.uk/datasets/TS006/editions/2021/versions/4

## Tools
For this project, the following Python libraries were used:

- pandas - for data analysis
- seaborn - for visualisations
- folium - for geospatial visualisations
- scikit-learn - for machine learning models (linear regression and k-means clustering)
- statsmodels - for time series analysis

Tableau was used for a storyboard for the final report.
